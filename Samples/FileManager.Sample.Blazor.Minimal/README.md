# FileManager.Sample.Blazor.Minimal

Blazor Server 宿主 · 最小集成：只读 ContentRoot + FileExplorer。

```bash
dotnet run --project Samples/FileManager.Sample.Blazor.Minimal/FileManager.Sample.Blazor.Minimal.csproj
```

| 端点 | 地址 |
|------|------|
| 首页 | http://localhost:2130 |
| FileExplorer | http://localhost:2130/Browser/ |
| 默认目录浏览 | http://localhost:2130/Default/ |
