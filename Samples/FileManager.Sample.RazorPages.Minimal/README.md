# FileManager.Sample.RazorPages.Minimal

Razor Pages 宿主 · 最小集成：只读 ContentRoot + FileExplorer。

```bash
dotnet run --project Samples/FileManager.Sample.RazorPages.Minimal/FileManager.Sample.RazorPages.Minimal.csproj
```

| 端点 | 地址 |
|------|------|
| 首页 | http://localhost:2115 |
| FileExplorer | http://localhost:2115/Browser/ |
| 默认目录浏览 | http://localhost:2115/Default/ |
