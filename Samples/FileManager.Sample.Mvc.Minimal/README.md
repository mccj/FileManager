# FileManager.Sample.Mvc.Minimal

MVC 宿主 · 最小集成：只读 ContentRoot + FileExplorer。

```bash
dotnet run --project Samples/FileManager.Sample.Mvc.Minimal/FileManager.Sample.Mvc.Minimal.csproj
```

| 端点 | 地址 |
|------|------|
| 首页 | http://localhost:2120 |
| FileExplorer | http://localhost:2120/Browser/ |
| 默认目录浏览 | http://localhost:2120/Default/ |
